PROCESSUS COMPLET DE CRÉATION D’AURX :

AurX a été construit progressivement à travers plusieurs phases d’évolution :

1. Phase d’idée initiale
- Naissance de l’idée d’un assistant IA personnel.
- Objectif : créer une IA accessible directement depuis un téléphone.

2. Phase de premiers tests
- Création de petits chatbots expérimentaux.
- Tests de génération de réponses simples.
- Compréhension du fonctionnement des modèles IA.

3. Phase d’expérimentation backend
- Mise en place des premières API.
- Tests de communication entre frontend et backend.
- Découverte du fonctionnement des requêtes IA.

4. Phase d’amélioration du modèle
- Création d’un MiniLLM simple.
- Tests de génération de texte avec tokenizer.
- Expérimentations sur la cohérence des réponses.

5. Phase système utilisateur
- Ajout d’un système de login.
- Gestion des utilisateurs avec API keys.
- Introduction des crédits et des rôles (free / owner).

6. Phase architecture multi-systèmes
- Séparation en plusieurs composants :
  - backend principal AurX
  - backend dashboard
  - futur backend memory
- Mise en place d’un système distribué.

7. Phase prompt engineering
- Création d’un prompt structuré pour AurX.
- Ajout de règles de comportement, style et identité.
- Optimisation des réponses IA.

8. Phase PWA
- Transformation du projet en Progressive Web App.
- Déploiement sur Vercel.
- Accès direct via navigateur mobile.

9. Phase évolution actuelle
- Stabilisation du système.
- Amélioration de la cohérence des réponses.
- Préparation d’un système mémoire externe.
- Optimisation de l’expérience utilisateur.
