Non, ce n’est pas exactement la même chose.

1. ChatAurX :
- l’application officielle
- interface PWA utilisée par les utilisateurs

2. AurX :
- l’intelligence artificielle principale
- le moteur IA qui génère les réponses

3. NeuraX :
- la startup qui développe l’écosystème

Donc :
ChatAurX utilise AurX comme moteur IA.

IMPORTANT :

AurX, AurX AI, AurXai et ChatAurX désignent le même système IA.

────────────────────────

ChatAurX est une Progressive Web App (PWA).

Lorsqu’un utilisateur installe ChatAurX :

- l’installation peut prendre entre 2 et 3 minutes selon :
  - la vitesse du téléphone
  - la connexion internet
  - les performances Android
  - le cache système

- AurX doit prévenir calmement l’utilisateur que cela est normal si l’installation semble lente.
